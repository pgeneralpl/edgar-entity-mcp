Contact & Abuse

edgar-entity-mcp · Terms · Acceptable Use · Privacy · Contact & Abuse

All requests go to one address: patryk.general@mail.grokbot.com. Please use one of the subject lines below so we can prioritise your message.

Report abuse

Subject: Abuse. Report misuse of the Service, such as harassment, stalking or doxxing using registry or insider data, bulk harvesting, attempts to bypass limits, FCRA-type use, or traffic that harms the SEC or state portals. Include as much as you can: what happened, when (with time zone), and any evidence such as screenshots, URLs, user agents, API key prefixes or IP addresses. We review reports and act under our Acceptable Use Policy.

Personal data requests

Subject: Data subject request. Use this if you appear in data returned by the Service (for example as a registered agent or Form 4 insider) and want to object, or to request access, erasure or suppression. Also use it if you are an API user exercising your GDPR rights. Include the source (SEC or state), the entity name or ID, or the filing, and the specific data concerned. We respond within one month. See our Privacy Policy. To correct an official record, contact the SEC, the filer or the relevant state agency, since we cannot change the original source.

Security issues

Subject: Security. Please report vulnerabilities privately by email, not as public GitHub issues. Include steps to reproduce and the potential impact. Do not access other users' data, degrade the Service or overload upstream sources while testing. We will acknowledge good-faith reports and will not pursue action against researchers who follow these rules.

General questions and bugs

For bugs and feature requests, please open an issue at github.com/pgeneralpl/edgar-entity-mcp/issues. For anything else, email patryk.general@mail.grokbot.com.

This Service is not affiliated with the U.S. SEC or any state government. To report problems with official records, contact the source agency.
